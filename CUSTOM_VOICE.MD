# Custom Voices: F6 & F7 (Anime Style)

## Overview

F6 and F7 are custom voice style embeddings generated by applying directional shifts to the F1 (Female 1) voice embedding. Both target "anime-style" voices — higher-pitched, more expressive, and energetic. F7 pushes further into the cute/energetic extreme than F6.

## How It Was Generated

### 1. Voice Embedding Structure

Supertonic voice styles consist of two embedding tensors:

| Tensor | Shape | Purpose |
|--------|-------|---------|
| `style_ttl` | `[1, 50, 256]` | Voice timbre/character conditioning (text encoder + vector estimator) |
| `style_dp` | `[1, 8, 16]` | Duration/speed conditioning (duration predictor) |

### 2. Computing the "Anime" Direction

The shift direction was derived from the existing voice cluster:

1. **PCA on all 10 voices** — Principal Component Analysis on the flattened `style_ttl` embeddings reveals the main axis of variation in the voice space.

2. **Gender direction** — The vector from the male centroid (M1–M5) toward the female centroid (F1–F5) captures pitch/timbre differences.

3. **Combined direction** — The anime direction is a blend:
   ```
   anime_dir = 0.7 × gender_dir + 0.3 × pc1
   ```
   Weighted toward the gender direction (high-pitch) with a small expressiveness component from PC1.

### 3. Applying the Shift

```python
f6_ttl = f1_ttl + 0.35 × mean_inter_voice_distance × anime_dir_normalized
f6_dp  = f1_dp × 0.92   # shorter durations → faster/more energetic speech
```

- **Scale factor 0.35** — ~40% of the typical inter-voice L2 distance, ensuring F6 is noticeably different but still within the model's distribution.
- **DP bias 0.92** — Reduces predicted durations by 8%, producing slightly faster speech typical of anime characters.

### 4. Validation

F6 sits well within the existing voice cluster:

| Voice | Cosine Similarity | L2 Distance |
|-------|------------------|-------------|
| M1 | 0.9123 | 2.9961 |
| M2 | 0.9050 | 3.1187 |
| M3 | 0.8365 | 4.0880 |
| M4 | 0.9016 | 3.1728 |
| M5 | 0.8852 | 3.4270 |
| **F1** | **0.9914** | **0.9480** |
| F2 | 0.9472 | 2.3268 |

| F5 | 0.9241 | 2.7884 |

**Intra-cluster L2 range**: 1.85–3.69 (F6 vs F1 = 0.95, well within bounds)

## Reproducing

Run the generation script:

```bash
cd /path/to/companion
python3 << 'PYEOF'
import json, numpy as np

voices = {}
for v in ['M1','M2','M3','M4','M5','F1','F2','F3','F4','F5']:
    with open(f'features/tts/assets/supertonic/voice_styles/{v}.json') as f:
        d = json.load(f)
    voices[v] = {
        'ttl': np.array(d['style_ttl']['data']),
        'dp': np.array(d['style_dp']['data'])
    }

ttl_matrix = np.array([voices[v]['ttl'].flatten() for v in voices])
mean_vec = ttl_matrix.mean(axis=0)
centered = ttl_matrix - mean_vec
U, S, Vt = np.linalg.svd(centered, full_matrices=False)
pc1 = Vt[0]

male_centroid = ttl_matrix[:5].mean(axis=0)
female_centroid = ttl_matrix[5:].mean(axis=0)
gender_dir = female_centroid - male_centroid
gender_dir = gender_dir / np.linalg.norm(gender_dir)

anime_dir = 0.7 * gender_dir + 0.3 * pc1
anime_dir = anime_dir / np.linalg.norm(anime_dir)

dists = []
for a in voices:
    for b in voices:
        if a >= b: continue
        dists.append(np.linalg.norm(voices[a]['ttl'].flatten() - voices[b]['ttl'].flatten()))
mean_dist = np.mean(dists)

f1_ttl = voices['F1']['ttl'].flatten()
f1_dp = voices['F1']['dp'].flatten()

f6_ttl = (f1_ttl + 0.35 * mean_dist * anime_dir).reshape(1, 50, 256).tolist()
f6_dp = (f1_dp * 0.92).reshape(1, 8, 16).tolist()

f6 = {
    "style_ttl": {"data": f6_ttl, "dims": [1, 50, 256]},
    "style_dp": {"data": f6_dp, "dims": [1, 8, 16]}
}

with open('features/tts/assets/supertonic/voice_styles/F6.json', 'w') as f:
    json.dump(f6, f)

print("F6.json generated")
PYEOF
```

# Custom Voice: F7 (Cute Anime Style)

## Overview

F7 is a more aggressive "cute anime" voice — even higher-pitched and faster than F6. Generated from F1 with a stronger directional shift and more energetic speed bias.

## Generation Parameters

| Parameter | F6 | F7 |
|-----------|----|----|
| Base voice | F1 | F1 |
| Direction weights | 0.7 × gender + 0.3 × pc1 | 0.8 × gender + 0.2 × pc1 |
| Shift magnitude | 0.35 × mean_dist | 0.55 × mean_dist |
| Speed bias (dp) | ×0.92 | ×0.85 |

## Similarity to F6

F7 vs F6: cosine similarity 0.997, L2 distance 0.59 — very close, both in the "anime" cluster but F7 is pushed further toward the high-pitch/energetic extreme.

## Limitations

- The speaker encoder model (audio → embedding) was never open-sourced by Supertone. This embedding was created by perturbing an existing voice, not from reference audio.
- Voice Builder (supertonic.supertone.ai/voice_builder) is no longer accessible (shut down August 2026).
- For true voice cloning from audio, use a different TTS system (F5-TTS, OpenVoice v2, etc.).

## Creating More Voices

To generate additional custom voices, modify the parameters:

- **Base voice**: Change `F1` to any existing voice (M1–M5, F1–F5)
- **Direction weights**: Adjust gender_dir vs pc1 balance (higher gender = higher pitch, higher pc1 = more expressive)
- **Shift magnitude**: Keep under 0.55 to stay in-distribution (0.35 = moderate, 0.55 = aggressive)
- **Speed bias**: Lower = faster (0.92 = moderate, 0.85 = fast, range 0.80–1.0)
